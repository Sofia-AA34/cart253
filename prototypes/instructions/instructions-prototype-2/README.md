# Hypnosis

Sofia Allashukurovs

[View this project online](https://sofia-aa34.github.io/cart253/prototypes/instructions/instructions-prototype-2/)

## Description

It is a flickering iris that hypnotizes the user. It is made to catch the eye and be a fun Halloween preview. 
It is made to be interactive as the color of the pupil turns red when pressed.
